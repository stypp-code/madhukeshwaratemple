## Asset processing and publication note

- Source files were downloaded from Commons’ file redirect, not hotlinked in the site. Original source downloads are retained in `public/images/temple/originals/` where available; the Triloka Mantapa original should be re-downloaded into that archive before production packaging.
- Processing is limited to resizing and JPEG recompression for delivery; no content was added or removed.
- On public deployment, show creator + licence attribution adjacent to images or in an easily reachable credit page. The image title attribute alone is insufficient for a public-facing attribution requirement.
- Confirm current Commons file pages and licence status immediately before launch. If a file’s author/licence cannot be verified, remove it and use an intentional photography placeholder.
- Still missing: a clearly licensed festival/Rathotsava photograph, a verified public deity photograph, and approved contemporary temple imagery. The site does not use generic stock or generated temple images.
